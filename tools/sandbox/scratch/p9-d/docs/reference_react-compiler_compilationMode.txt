Type &#x27;infer&#x27; | &#x27;syntax&#x27; | &#x27;annotation&#x27; | &#x27;all&#x27; Default value &#x27;infer&#x27; Options &#x27;infer&#x27; (default): The compiler uses intelligent heuristics to identify React components and hooks: Functions explicitly annotated with &quot;use memo&quot; directive Functions that are named like components (PascalCase) or hooks ( use prefix) AND create JSX and/or call other hooks &#x27;annotation&#x27; : Only compile functions explicitly marked with the &quot;use memo&quot; directive. Ideal for incremental adoption. &#x27;syntax&#x27; : Only compile components and hooks that use Flow’s component and hook syntax. &#x27;all&#x27; : Compile all top-level functions. Not recommended as it may compile non-React functions. Caveats The &#x27;infer&#x27; mode requires functions to follow React naming conventions to be detected Using &#x27;all&#x27; mode may negatively impact performance by compiling utility functions The &#x27;syntax&#x27; mode requires Flow and won’t work with TypeScript Regardless of mode, functions with &quot;use no memo&quot; directive are always skipped Usage Default inference mode The default &#x27;infer&#x27; mode works well for most codebases that follow React conventions: { compilationMode : &#x27;infer&#x27;
