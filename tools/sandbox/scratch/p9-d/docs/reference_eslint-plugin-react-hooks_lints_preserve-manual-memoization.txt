React Compiler will only compile components and hooks if its inference matches or exceeds the existing manual memoization . Rule Details React Compiler preserves your existing useMemo , useCallback , and React.memo calls. If you’ve manually memoized something, the compiler assumes you had a good reason and won’t remove it. However, incomplete dependencies prevent the compiler from understanding your code’s data flow and applying further optimizations. Invalid Examples of incorrect code for this rule: // ❌ Missing dependencies in useMemo function Component ( { data , filter } ) { const filtered = useMemo ( ( ) =&gt; data . filter ( filter ) , [ data ] // Missing &#x27;filter&#x27; dependency ) ; return &lt; List items = { filtered } /&gt; ; } // ❌ Missing dependencies in useCallback function Component ( { onUpdate , value } ) { const handleClick = useCallback ( ( ) =&gt; { onUpdate ( value ) ; } , [ onUpdate ] ) ; // Missing &#x27;value&#x27; return &lt; button onClick = { handleClick } &gt; Update &lt;/ button &gt; ; } Valid Examples of correct code for this rule: // ✅ Complete dependencies function Component ( { data , filter } ) { const filtered = useMemo ( ( ) =&gt; data . filter ( filter ) , [ data , filter ] // All dependencies included ) ; return &lt; List items = { filtered } /&gt; ; } // ✅ Or let the compiler handle it function Component ( { data , filter } ) { // No manual memoization needed const filtered = data . filter ( filter ) ; return &lt; List items = { filtered } /&gt; ; } Troubleshooting Should I remove my manual memoization?
